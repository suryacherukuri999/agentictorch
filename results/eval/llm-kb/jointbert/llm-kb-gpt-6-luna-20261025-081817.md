# AgenticTorch report: jointbert

**Result: 1.70x faster, loss within noise** on an NVIDIA L4.

- Command: `TOKENIZERS_PARALLELISM=false HF_HOME=hf HF_HUB_OFFLINE=1 python main.py --task atis --model_type bert --model_dir atis_model --do_train`
- Baseline: 140.7 ms/step over 2 runs
- Model: gpt-6-luna, 8 turns, 32303 input and 426 output tokens

Enabled CUDA bfloat16 autocast for training forward passes and moved training-loss accumulation onto the device, eliminating the per-step loss.item() synchronization while preserving the returned scalar loss.
