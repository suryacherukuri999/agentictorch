# AgenticTorch report: nerf-pytorch

**Result: 2.55x faster, loss within noise** on an NVIDIA L4.

- Command: `python run_nerf.py --config configs/lego.txt`
- Baseline: 183.8 ms/step over 2 runs
- Model: gpt-6-luna, 9 turns, 120545 input and 823 output tokens

Enabled CUDA bfloat16 autocast for the training render/forward pass, compiled the coarse and fine NeRF modules on CUDA, and enabled TF32 for CUDA matrix operations. These changes accelerate GPU training while retaining the same model, data, batch size, optimizer settings, step count, and logging/saving behavior.
