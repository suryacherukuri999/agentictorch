# AgenticTorch report: bench-resnet-workers0

**Result: 2.61x faster, loss within noise** on an NVIDIA L4.

- Command: `python train.py --data data`
- Baseline: 122.9 ms/step over 2 runs
- Model: ornith-1.5:9b, 5 turns, 12058 input and 5776 output tokens

Addressed both flagged slowdowns in train.py: (1) wrapped the model in torch.compile so the dominant forward/backward pass is compiled, and (2) changed the training DataLoader from num_workers=0 to num_workers=4 with persistent_workers=True (matching the already-fast test_loader) so data loading runs off the main thread and workers are reused across epochs. No model/data/hyperparameters/printing behavior changed.
