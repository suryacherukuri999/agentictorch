# AgenticTorch report: vit-pytorch

**Result: 1.26x faster, loss within noise** on an NVIDIA L4.

- Command: `python train_vit_decorr.py`
- Baseline: 28.7 ms/step over 2 runs
- Model: gpt-6-luna, 5 turns, 9523 input and 261 output tokens

Enabled parallel DataLoader workers and pinned host memory to improve input throughput. Replaced explicit .item() calls in per-step logging with detached scalar tensors, preserving the printed values while avoiding explicit synchronization calls.
