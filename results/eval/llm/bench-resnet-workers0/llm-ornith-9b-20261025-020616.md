# AgenticTorch report: bench-resnet-workers0

**Result: 2.48x faster, loss within noise** on an NVIDIA L4.

- Command: `python train.py --data data`
- Baseline: 121.6 ms/step over 2 runs
- Model: ornith-1.5:9b, 6 turns, 13637 input and 9791 output tokens

Addressed both flagged slowdowns in train.py: (1) training DataLoader used num_workers=0 (data loading serialized on the main thread against GPU compute) — changed to num_workers=4 with persistent_workers=True to match the test loader; (2) torch.compile was not used — wrapped the model in torch.compile(mode="max-autotune") so the bfloat16 channels-last forward/backward passes get compiled and autotuned. No changes to model, data, batch size, lr, step count, or outputs.

| 1 | llm patch, made without measuring | 121.6 ms/step | 49.0 ms/step | kept: 2.48x faster, loss within noise |
