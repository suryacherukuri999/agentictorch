# AgenticTorch report: jointbert

**Result: 1.66x faster, loss within noise** on an NVIDIA L4.

- Command: `TOKENIZERS_PARALLELISM=false HF_HOME=hf HF_HUB_OFFLINE=1 python main.py --task atis --model_type bert --model_dir atis_model --do_train`
- Baseline: 134.0 ms/step over 2 runs
- Model: gpt-6-luna, 7 turns, 36513 input and 442 output tokens

Removed the per-step loss.item() synchronization by accumulating detached losses on-device and converting to a Python scalar only once at the end. Enabled CUDA TF32 for faster matrix operations on supported GPUs.
