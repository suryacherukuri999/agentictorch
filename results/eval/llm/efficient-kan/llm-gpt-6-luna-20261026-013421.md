# AgenticTorch report: efficient-kan

**Result: 3.39x faster, loss within noise** on an NVIDIA L4.

- Command: `PYTHONPATH=src:$PYTHONPATH python examples/mnist.py`
- Baseline: 17.7 ms/step over 2 runs
- Model: gpt-6-luna, 7 turns, 11316 input and 766 output tokens

Improved MNIST throughput with CUDA bfloat16 autocast, CUDA-only torch.compile, pinned-memory multiworker loaders, nonblocking transfers, and set_to_none gradient clearing. Kept the existing per-step progress values and validation outputs unchanged.
