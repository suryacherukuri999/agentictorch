- Baseline: 560.0 ms/step over 2 runs
- Model: gpt-6-luna, 18 turns, 176524 input and 778 output tokens

Added bfloat16 autocast, which improved throughput substantially (about 1.35x), and persistent training DataLoader workers, which further reduced measured step time. Fused Adam gave a smaller additional improvement. Asynchronous target transfer was tested but reverted because it was within benchmark noise. No further benchmark rounds remain.

## Changes

| # | Change | Before | After | Outcome |
|---|---|---|---|---|
| 1 | Use CUDA bfloat16 autocast for model forward and loss to accelerate L4 tensor-core convolutions. | 546.4 ms/step | 406.0 ms/step | kept: 1.35x faster, loss within noise |
| 2 | Keep training DataLoader workers alive across epochs to avoid worker restart overhead. | 363.1 ms/step | 265.9 ms/step | kept: 1.37x faster, loss within noise |
| 3 | Make target transfer asynchronous, matching the pinned-memory image transfer. | 263.5 ms/step | 263.6 ms/step | reverted: 1.00x is within noise |
| 4 | Enable fused CUDA Adam implementation to reduce optimizer kernel overhead. | 280.5 ms/step | 264.7 ms/step | kept: 1.06x faster, loss within noise |
