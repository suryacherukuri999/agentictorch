# AgenticTorch report: efficient-kan

**Result: 3.40x faster, loss within noise** on an NVIDIA L4.

- Command: `PYTHONPATH=src:$PYTHONPATH python examples/mnist.py`
- Baseline: 17.3 ms/step over 2 runs
- Model: gpt-6-luna, 24 turns, 132685 input and 1183 output tokens

Reduced the dominant DataLoader wait by using four pinned-memory workers and nonblocking transfers, improving throughput from 17.3 to 6.8 ms/step. Compiling the model provided a further speedup to 5.1 ms/step with loss within noise. Fused AdamW and set_to_none gradient clearing were tested but did not beat the best version beyond noise, so they were reverted.

## Changes

| # | Change | Before | After | Outcome |
|---|---|---|---|---|
| 1 | Use worker processes and pinned DataLoader batches with nonblocking CUDA transfers to reduce the measured data-loading wait. | 17.5 ms/step | 6.8 ms/step | kept: 2.58x faster, loss within noise |
| 2 | Enable fused AdamW to combine optimizer operations and reduce GPU kernel overhead. | 7.1 ms/step | 6.9 ms/step | reverted: 1.04x is within noise |
| 3 | Set gradients to None when clearing them to avoid zero-fill memory operations before backward. | 6.5 ms/step | 7.4 ms/step | reverted: 0.90x is within noise |
| 4 | Compile the KAN model to fuse operations and reduce Python and kernel-launch overhead. | 6.9 ms/step | 5.1 ms/step | kept: 1.37x faster, loss within noise |
