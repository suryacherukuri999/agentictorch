# AgenticTorch report: jointbert

**Result: 2.65x faster, loss within noise** on an NVIDIA L4.

- Command: `TOKENIZERS_PARALLELISM=false HF_HOME=hf HF_HUB_OFFLINE=1 python main.py --task atis --model_type bert --model_dir atis_model --do_train`
- Baseline: 137.0 ms/step over 2 runs
- Model: gpt-6-luna, 20 turns, 149472 input and 942 output tokens

Enabled CUDA bfloat16 autocast (1.78x faster), fused AdamW (additional 1.32x faster), and torch.compile(mode='reduce-overhead') (additional 1.14x faster). Best measured speed is 51.7 ms/step versus 137.0 ms/step baseline, with loss within noise. Moving loss accumulation to the GPU to avoid per-step loss.item() synchronization was tested but reverted because the speedup was within noise.

## Changes

| # | Change | Before | After | Outcome |
|---|---|---|---|---|
| 1 | Enable CUDA bfloat16 autocast for model forward and loss to use L4 Tensor Cores and reduce activation bandwidth. | 137.6 ms/step | 77.7 ms/step | kept: 1.78x faster, loss within noise |
| 2 | Use fused AdamW CUDA implementation to combine optimizer elementwise operations and reduce launch overhead. | 80.8 ms/step | 61.1 ms/step | kept: 1.32x faster, loss within noise |
| 3 | Accumulate detached training loss on device and transfer once at return, removing per-step loss.item() host-device synchronization. | 55.8 ms/step | 54.7 ms/step | reverted: 1.02x is within noise |
| 4 | Compile the CUDA model with reduce-overhead to reduce Python and kernel launch overhead during training. | 58.9 ms/step | 51.7 ms/step | kept: 1.14x faster, loss within noise |
