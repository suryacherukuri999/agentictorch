- Baseline: 545.3 ms/step over 2 runs
- Model: gpt-6-luna, 20 turns, 159625 input and 1092 output tokens

Added CUDA bfloat16 autocast around the training forward/loss, which benchmarked 1.28x faster with loss within noise (best 426.8 ms/step versus 545.3 baseline). Channels-last format, zero_grad(set_to_none=True), and fused Adam did not beat the best version beyond noise and were reverted.

## Changes

| # | Change | Before | After | Outcome |
|---|---|---|---|---|
| 1 | Use CUDA bfloat16 autocast for the diffusion model forward and loss, reducing convolution compute cost on L4 while retaining float32 master parameters. | 554.1 ms/step | 432.0 ms/step | kept: 1.28x faster, loss within noise |
| 2 | Keep model and image batches in channels_last format alongside bfloat16 autocast to improve convolution Tensor Core throughput. | 428.2 ms/step | 461.1 ms/step | reverted: 0.93x is within noise |
| 3 | Set gradients to None when zeroing Adam gradients, avoiding unnecessary writes and allowing efficient gradient allocation. | 427.8 ms/step | 427.0 ms/step | reverted: 1.00x is within noise |
| 4 | Use fused CUDA Adam to combine optimizer update kernels and reduce per-step launch overhead. | 426.8 ms/step | 422.5 ms/step | reverted: 1.01x is within noise |
