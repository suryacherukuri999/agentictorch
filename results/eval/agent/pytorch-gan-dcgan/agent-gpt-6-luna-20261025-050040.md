Configured the MNIST DataLoader to use the existing n_cpu setting, pinned memory on CUDA, and persistent workers. This overlapped data loading with training and benchmarked 2.08× faster (13.6 ms/step) with loss within noise. A non-blocking batch transfer change was tested but reverted because it was within benchmark noise. No other promising changes remain.

## Changes

| # | Change | Before | After | Outcome |
|---|---|---|---|---|
| 1 | Use configured DataLoader workers, pinned batches, and persistent workers to overlap MNIST loading with GPU training. | 28.2 ms/step | 13.6 ms/step | kept: 2.08x faster, loss within noise |
| 2 | Transfer pinned image batches to CUDA non-blockingly to avoid a synchronous host-device copy. | 13.4 ms/step | 13.4 ms/step | reverted: 0.99x is within noise |
