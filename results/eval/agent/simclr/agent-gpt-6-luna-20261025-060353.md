# AgenticTorch report: simclr

**Result: 2.06x faster, loss within noise** on an NVIDIA L4.

- Command: `python main.py`
- Baseline: 418.4 ms/step over 2 runs
- Model: gpt-6-luna, 16 turns, 114102 input and 829 output tokens

Added bfloat16 autocast around the model and contrastive loss, then converted the model and input batches to channels_last. Both changes passed quick checks and benchmarks; together they improved throughput from 418.4 ms/step to about 205.7 ms/step with loss within noise. Tried set_to_none gradient clearing and creating loss labels directly on-device, but neither showed a speedup beyond benchmark noise, so those edits were reverted.

## Changes

| # | Change | Before | After | Outcome |
|---|---|---|---|---|
| 1 | Use CUDA bfloat16 autocast for model and contrastive loss to accelerate convolution and tensor-core operations. | 413.7 ms/step | 264.1 ms/step | kept: 1.57x faster, loss within noise |
| 2 | Convert ResNet and input batches to channels_last, which can improve convolution throughput with bfloat16. | 252.6 ms/step | 210.3 ms/step | kept: 1.20x faster, loss within noise |
| 3 | Set gradients to None during zero_grad to avoid zero-filling gradient buffers each step. | 213.5 ms/step | 213.8 ms/step | reverted: 1.00x is within noise |
| 4 | Create contrastive-loss labels directly on the target device, avoiding a CPU allocation and host-to-device copy. | 205.7 ms/step | 203.3 ms/step | reverted: 1.01x is within noise |
