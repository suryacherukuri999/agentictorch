- Baseline: 417.0 ms/step over 2 runs
- Model: gpt-6-luna, 19 turns, 130727 input and 899 output tokens

Enabled CUDA FP16 autocast for the model and contrastive loss, switched model and inputs to channels_last, and enabled cuDNN autotuning for fixed-size convolutions. These changes passed quick checks and improved measured throughput from 417.0 ms/step to 187.0 ms/step with loss within noise. Direct-on-device label creation was tested but reverted because it was within benchmark noise.

## Changes

| # | Change | Before | After | Outcome |
|---|---|---|---|---|
| 1 | Use CUDA autocast FP16 for model and contrastive loss to accelerate convolutions on L4. | 420.3 ms/step | 250.8 ms/step | kept: 1.68x faster, loss within noise |
| 2 | Create contrastive loss labels directly on the target device, avoiding CPU allocation and host-to-device copy. | 237.7 ms/step | 234.6 ms/step | reverted: 1.01x is within noise |
| 3 | Run ResNet inputs and weights in channels_last format, which can improve Tensor Core convolution throughput with AMP. | 244.2 ms/step | 191.2 ms/step | kept: 1.28x faster, loss within noise |
| 4 | Enable cuDNN autotuning for the fixed-size convolution workload to select faster convolution algorithms. | 195.4 ms/step | 187.0 ms/step | kept: 1.05x faster, loss within noise |
