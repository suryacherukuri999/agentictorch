## Changes

| # | Change | Before | After | Outcome |
|---|---|---|---|---|
| 1 | Increased DataLoader num_workers from 0 to 4 and added persistent_workers so CPU-bound augmentation runs in worker subprocesses, overlapping with GPU training and eliminating the 85% idle-GPU wait. | 122.9 ms/step | 49.1 ms/step | kept: 2.50x faster, loss within noise |
| 2 | Added torch.compile to the model to fuse the ResNet-18 forward/backward ops and reduce kernel launch overhead on the now GPU-bound training loop. | 49.4 ms/step | 47.5 ms/step | kept: 1.04x faster, loss within noise |
| 3 | Tightened torch.compile to dynamic=False (fixed ResNet-18 architecture, no dynamic shapes) with reduce-overhead=True to fuse more ops and cut kernel launch overhead. | 43.3 ms/step | failed (no results (exit code 1)) | reverted: run failed: no results (exit code 1) |
| 4 | Added reduce-overhead=True to torch.compile to fuse ops and cut kernel launch overhead on the GPU-bound loop. | 45.6 ms/step | failed (no results (exit code 1)) | reverted: run failed: no results (exit code 1) |
| 5 | Added a custom collate_fn that batches samples into channels_last format on the CPU worker, so the per-step GPU transfer becomes a pure pinned-memory copy instead of a transpose+copy. | 43.2 ms/step | failed (UnboundLocalError: cannot access local variable '_channels_last_collate' where it is not associated with a value) | reverted: run failed: UnboundLocalError: cannot access local variable '_channels_last_collate' where it is not associated with a value |
