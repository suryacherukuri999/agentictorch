# AgenticTorch report: rectified-flow-pytorch

- Command: `HF_HOME=hf HF_HUB_OFFLINE=1 HF_DATASETS_OFFLINE=1 python train_oxford.py`
- Baseline: 431.2 ms/step over 2 runs
- Model: gpt-6-luna, 12 turns, 93902 input and 600 output tokens

Added four persistent DataLoader workers and pinned memory in the shared Trainer DataLoader. This passed quick_check and benchmarked 1.18× faster (373.5 ms/step) with loss within noise. Tried fused Adam, but it was within benchmark noise and was reverted. No further changes made.

## Changes

| # | Change | Before | After | Outcome |
|---|---|---|---|---|
| 1 | Use four persistent DataLoader workers and pinned host memory to overlap Oxford image loading and host-to-device transfers. | 442.0 ms/step | 373.5 ms/step | kept: 1.18x faster, loss within noise |
| 2 | Enable fused CUDA Adam to combine optimizer operations and reduce per-step kernel overhead. | 376.0 ms/step | 369.3 ms/step | reverted: 1.02x is within noise |
